# Database

Este diretório contém tudo relacionado ao banco de dados do projeto.

## Estrutura

- `schema.sql` — Definição das tabelas e relacionamentos.
- `migrations/` — Scripts de migração do banco de dados.
- `seeds/` — Dados iniciais/fictícios para desenvolvimento e testes.

## Como usar

1. Crie o banco de dados local.
2. Execute o `schema.sql` para criar as tabelas.
3. (Opcional) Execute os seeds para popular com dados de exemplo.
